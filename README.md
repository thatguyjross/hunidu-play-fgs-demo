# HuniDu Play FGS location demo

Live device recording for Google Play Console **Foreground Service → LOCATION** declaration (user-initiated carpool sharing).

## Video URL (use this in Play Console)

https://cdn.jsdelivr.net/gh/thatguyjross/hunidu-play-fgs-demo@main/fgs-location-demo.mp4

Also available: https://raw.githubusercontent.com/thatguyjross/hunidu-play-fgs-demo/main/fgs-location-demo.mp4

## What the video shows

1. Family → Rides → open a scheduled ride
2. Tap **I'm on my way** (starts location foreground service)
3. Ongoing notification **Sharing your ride** with **Stop sharing**
4. Live map / driver coordinates while sharing
